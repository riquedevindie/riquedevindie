## 👨‍💻 Sobre mim

Olá! Sou o **Rique**, desenvolvedor brasileiro apaixonado pela criação de jogos independentes.

Meu foco é o **desenvolvimento de jogos 2D com Godot Engine**, utilizando GDScript para programar mecânicas, sistemas e experiências interativas.

Gosto de aprender na prática, experimentar novas ideias e desenvolver projetos com identidade própria.

- 🎮 Desenvolvimento de jogos 2D
- 💻 Programação com GDScript
- 🕹️ Mecânicas de gameplay e movimentação
- ⚔️ Sistemas de combate e colisões
- 🧩 Lógica, eventos e interações
- 🛠️ Desenvolvimento de ferramentas para jogos
- 🚀 Evoluindo a cada projeto
